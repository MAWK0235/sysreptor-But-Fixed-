# Design AI Chat Plugin
This plugin provides an AI assistant floating chat window in the SysReptor design section to help you write HTML, Vue, and CSS templates.

## Installation
1. Edit `app.env` to add this plugin to `ENABLED_PLUGINS`. E.g.: `ENABLED_PLUGINS=cyberchef,checkthehash,designaichat`
2. Run `docker compose up -d` to restart.
3. Make sure you have an AI Model configured in Administration -> Settings.
